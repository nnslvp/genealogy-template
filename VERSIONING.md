# Правило: ничего не теряется

Эта папка — git-репозиторий. Каждое изменение фиксируется коммитом.

## Что версионируется
Всё: сканы документов (PDF, JPG), карточки предков, находки, письма в архивы, опросник.
Даже если файл случайно удалят или перезапишут, он восстанавливается командой `git checkout`.

## Что НЕ версионируется
Только сырые данные ДНК (`docs/dna/*.csv`, `*.zip`, `*.ged`) — они большие и содержат генетику живых людей.
Их резервная копия должна лежать отдельно, вне репозитория. Скриншоты и выводы по ДНК версионируются нормально.

## Автоматическое сохранение (главное правило)
В `~/.claude/settings.json` настроен хук `PostToolUse`: как только Claude создаёт или правит любой файл
внутри `~/work/genealogy*/`, запускается `save.sh` этой папки — он делает коммит с именем изменённого файла
и отправляет его на GitHub. Если сети нет, коммит остаётся локальным и уедет при следующем сохранении.

Это значит: специально просить «сохрани» не нужно, каждая правка уже в истории.

### Хук автосохранения (если настраиваете на другом компьютере)
Добавить в `~/.claude/settings.json` → `hooks.PostToolUse` элемент:
```json
{
  "matcher": "Write|Edit|NotebookEdit",
  "hooks": [{
    "type": "command",
    "timeout": 30,
    "statusMessage": "Сохраняю в git...",
    "command": "jq -r '.tool_response.filePath // .tool_input.file_path // empty' | { read -r f; case \"$f\" in \"$HOME\"/work/genealogy*/*) root=\"${f#$HOME/work/}\"; root=\"$HOME/work/${root%%/*}\"; [ -x \"$root/save.sh\" ] && \"$root/save.sh\" \"Автосохранение: ${f#$root/}\" ;; esac; }"
  }]
}
```
Нужен `jq` (`brew install jq`). Посмотреть или отключить хук: команда `/hooks` в интерактивном `claude`.

## Как сохранить вручную
Нужно, если файлы вы меняли сами (в редакторе, Finder, сканером) — хук про это не знает.
```bash
cd ~/work/genealogy-{{SLUG}} && ./save.sh "что изменилось"
```
Без аргумента подставится дата и время.

## Как посмотреть историю
```bash
git -C ~/work/genealogy-{{SLUG}} log --oneline --stat
```

## Как вернуть удалённый или испорченный файл
```bash
cd ~/work/genealogy-{{SLUG}}
git log --oneline -- docs/<папка>/<файл>.pdf   # найти коммит
git checkout <коммит> -- docs/<папка>/<файл>.pdf
```

## Резервная копия вне компьютера
Приватный репозиторий на GitHub: `genealogy-{{SLUG}}` (создаётся командой из `setup.sh`).
Он и есть копия на случай потери диска — туда уходит каждое сохранение.

Восстановить архив на новом компьютере:
```bash
git clone git@github.com:<аккаунт>/genealogy-{{SLUG}}.git ~/work/genealogy-{{SLUG}}
```

**Держите его приватным.** Внутри будут паспортные данные, адреса, свидетельства о рождении живых людей.
Никому не давайте доступ (Settings → Collaborators) и не делайте репозиторий публичным.
