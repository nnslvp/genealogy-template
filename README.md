# Генеалогический поиск → roadmap ПМЖ/гражданство: шаблон

Это каркас рабочей папки для поиска предков под легализацию, снятый с проекта `~/work/genealogy`
(начат 10.09.2026). Правила, справочники и скрипты — общие; личных данных нет.

## Как завести проект для нового человека
```bash
~/work/genealogy-template/setup.sh <slug> "<Имя>" "<Имени>"
# пример: ~/work/genealogy-template/setup.sh anna "Анна" "Анны"
```
Скрипт создаст `~/work/genealogy-<slug>`, подставит имя во все файлы, сделает `git init`
и первый коммит, затем напечатает две команды, которые нужно выполнить руками:
создать **приватный** репозиторий на GitHub и проверить хук автосохранения.

## Что внутри
- `CLAUDE.md` — правила проекта для Claude: как вести карточки, источники, письма, что нельзя.
- `questionnaire.md` — опросник v1: с чего начинается работа. Заполнять прямо в файле.
- `persons.md`, `persons/`, `TRACKER.md`, `TODO.md`, `roadmap.md` — рабочие файлы, пока пустые каркасы.
- `docs/` — сканы документов: кидать в `docs/inbox/`, Claude разберёт и разложит.
- `findings/`, `letters/` — находки и черновики запросов.
- `handbook/` — справочник: источники, методика, запросы, чтение документов с ошибками, практика Карты поляка.
- `tree/` — интерактивное дерево из карточек.
- `save.sh`, `VERSIONING.md` — автосохранение в git и GitHub.

## С чего начать первую сессию
1. Открыть `claude` в новой папке. Он прочитает `CLAUDE.md` и знает правила.
2. Заполнить блок «О себе» в `questionnaire.md`, остальное — по мере опроса родни.
3. Положить в `docs/inbox/` свидетельства о рождении: своё, родителей, всё, что есть на дедов.
4. Сказать «разбери инбокс» — дальше Claude ведёт сам: карточки, реестр, трекер, план.

## Правила ведения (кратко)
- Каждая находка: источник (URL/архив/фонд), дата, что найдено, степень уверенности.
- Ничего платного не покупаем без явного согласия.
- Письма в архивы копим и отправляем только по слову владельца.
