# Генеалогический поиск → roadmap ПМЖ/гражданство: шаблон

Каркас рабочей папки для поиска предков под легализацию (Карта поляка, гражданство по происхождению,
репатриация) вместе с Claude Code. Снят с реального проекта 2026 года по Западной Беларуси.
Правила, справочники и скрипты — общие; личных данных нет. В справочниках примеры из первого дела
обезличены: `ФАМИЛИЯ-1`, `ДЕРЕВНЯ-1` и т. п. — читать как «подставь своё».

## Что нужно
- macOS или Linux, `git`, `python3`, `jq` (`brew install jq`).
- [Claude Code](https://claude.com/claude-code) в терминале: `npm install -g @anthropic-ai/claude-code`.
- Аккаунт на GitHub и `gh` (`brew install gh && gh auth login`) — для приватной резервной копии.

## Как начать: пять шагов
```bash
# 1. Взять шаблон
git clone https://github.com/nnslvp/genealogy-template.git ~/work/genealogy-template

# 2. Создать свой проект: slug латиницей, имя в именительном и родительном падеже
~/work/genealogy-template/setup.sh anna "Анна" "Анны"
#    → появится ~/work/genealogy-anna с подставленным именем и первым коммитом

# 3. Приватная копия на GitHub (команду скрипт напечатает сам)
gh repo create genealogy-anna --private --source ~/work/genealogy-anna --remote origin --push

# 4. Хук автосохранения — один раз, см. VERSIONING.md, раздел «Хук автосохранения»

# 5. Открыть Claude в папке проекта
cd ~/work/genealogy-anna && claude
```

## Первая сессия с Claude
1. Claude сам прочитает `CLAUDE.md` и знает правила проекта.
2. Заполните блок 0 «О себе» в `questionnaire.md` прямо в файле после «Ответ:». «Не знаю» — тоже ответ.
3. Положите в `docs/inbox/` сканы или фото: своё свидетельство о рождении, свидетельства родителей, всё, что есть на дедов.
4. Напишите Claude: **«разбери инбокс и ответы на опросник»**. Дальше он ведёт сам: карточки людей,
   реестр документов, трекер по прадедам, план следующих шагов и опросник v2 для родни.
5. Каждая правка сохраняется в git и на GitHub автоматически. Файлы, которые меняли руками — `./save.sh "что изменилось"`.

Типичные команды в дальнейшем: «что у нас на повестке», «проверь публичные базы по фамилии …»,
«подготовь письмо в ЗАГС …» (Claude только подготовит — отправка по вашему «да»), «собери дерево».

## Что внутри
| Папка / файл | Зачем |
|---|---|
| `CLAUDE.md` | правила для Claude: карточки, источники, письма, что нельзя |
| `questionnaire.md` | опросник v1, с него всё начинается |
| `persons.md`, `persons/` | сводка и карточки: один человек — один файл |
| `TRACKER.md` | восемь прадедов: есть ли документ о национальности |
| `TODO.md`, `roadmap.md` | что дальше и юридические маршруты по странам |
| `docs/` | сканы: `inbox/` для новых, папки по людям, реестр `INDEX.md` |
| `findings/`, `letters/` | находки и черновики запросов |
| `handbook/` | методика, источники, запросы, чтение документов с ошибками, практика Карты поляка |
| `tree/` | дерево из карточек: `python3 tree/build_tree.py && python3 tree/build_html.py` |
| `save.sh`, `VERSIONING.md` | автосохранение в git и GitHub |

## Правила ведения (кратко)
- Каждая находка: источник (URL/архив/фонд), дата, что найдено, степень уверенности.
- Ничего платного не покупаем без явного согласия.
- Письма в архивы копим и отправляем только по слову владельца. В письмах ни слова о Карте поляка.
- Проект держите приватным: внутри будут паспортные данные и адреса живых людей.
