# Стартовый промт для Claude Code

Скопируйте текст ниже целиком и вставьте в Claude Code (`claude` в терминале, любая папка).
Claude сам поставит нужное, создаст проект и поведёт дальше. Отвечайте на его вопросы простыми словами.

---

Ты помогаешь мне, человеку без технического опыта, начать поиск предков для легализации в Польше
(Карта поляка, гражданство по происхождению). Всё общение — по-русски, простыми словами, без жаргона.
Делай шаги по одному, после каждого коротко говори, что получилось, и спрашивай меня только то,
что действительно нужно. Не проси меня вводить команды руками: выполняй сам, а мне показывай результат.

Шаг 1. Окружение. Проверь, есть ли git, python3, jq, gh и Homebrew. Чего нет — поставь
(на macOS через Homebrew: `brew install git python jq gh`). Проверь `gh auth status`; если не авторизован,
запусти `gh auth login` и объясни мне, что нажимать в браузере.

Шаг 2. Шаблон. Склонируй https://github.com/nnslvp/genealogy-template.git в ~/work/genealogy-template
(если папка уже есть — сделай `git pull`). Прочитай README.md и CLAUDE.md шаблона: там правила проекта.

Шаг 3. Мой проект. Спроси у меня имя (как ко мне обращаться) и имя в родительном падеже («проект Анны»).
Придумай slug латиницей из имени. Выполни
`~/work/genealogy-template/setup.sh <slug> "<Имя>" "<Имени>"`. Покажи, что получилось.

Шаг 4. Резервная копия. Создай ПРИВАТНЫЙ репозиторий на GitHub командой, которую напечатал setup.sh
(`gh repo create genealogy-<slug> --private --source ~/work/genealogy-<slug> --remote origin --push`).
Проверь `gh repo view`, что visibility = PRIVATE. Объясни мне в двух фразах, зачем он и что его нельзя открывать.

Шаг 5. Автосохранение. В ~/.claude/settings.json добавь хук PostToolUse из файла
~/work/genealogy-<slug>/VERSIONING.md (раздел «Хук автосохранения»). Если файла settings.json нет — создай;
если есть — аккуратно добавь элемент в hooks.PostToolUse, ничего не удаляя, и проверь, что JSON валиден.
Проверь хук: создай в проекте файл docs/inbox/test.md, убедись, что появился коммит, удали файл и снова
убедись, что удаление закоммичено. Если хук не сработал — разберись, не оставляй на потом.

Шаг 6. Передача. Скажи мне, что установка закончена, и что дальше нужно закрыть эту сессию и открыть
Claude уже в папке проекта: `cd ~/work/genealogy-<slug> && claude`. Напиши мне первое сообщение,
которое я должна там отправить: «Прочитай CLAUDE.md и README.md. Веди меня по опроснику questionnaire.md:
задавай вопросы блоками по одному, записывай мои ответы в docs/answers/ дословно, потом разбери docs/inbox/
и скажи, какие документы искать дома первыми».

Правила на всё время: ничего не покупать и не отправлять в архивы без моего явного «да»; при любой ошибке
сначала объяснить, что случилось, потом чинить; не удалять ничего, кроме тестового файла из шага 5.
Начинай с шага 1.
