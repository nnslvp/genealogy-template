# findings/ — результаты поиска

Один файл — одна тема (источник, зацепка, человек). Имена файлов латиницей:

| Префикс | Что | Пример |
|---|---|---|
| `search-<тема>-<дата>.md` | разведка по базе или группе архивов: что проверили, что нашли, что пусто | `search-publichnye-bazy-2026-10-12.md` |
| `lead-<человек>.md` | зацепка: гипотеза, что её подтверждает, план проверки | `lead-ivanov-1899.md` |
| `NAYDEN-<тема>.md` | подтверждённая находка с полным шифром и цитатой | `NAYDEN-ivanov-podvignaroda.md` |
| `REZULTAT-<тема>.md` | итог проверки (в т. ч. отрицательный) | `REZULTAT-dnk-2026-10.md` |
| `law-<страна>-<дата>.md` | разбор закона с цитатами | `law-poland-2026-10.md` |
| `metodika-*.md` | методические выводы | `metodika-sovetskie-zapisi.md` |

## Что обязательно в каждом файле
1. Дата и повод (по чьему вопросу, из какого ответа опросника).
2. **Источник**: URL и номер записи, либо архив, фонд, опись, дело, лист.
3. **Дословная цитата** нужного фрагмента, не пересказ.
4. Что совпало и что не совпало с нашим человеком (`handbook/03`, «как понять, что это наш»).
5. Степень уверенности: ✅ документ · 🟡 косвенно · ⚫ проверено, не наш / не подходит.
6. **Что дальше**: следующий шаг с адресатом.
7. Обновлены ли карточки в `persons/` и строка в `TRACKER.md` — да/нет.

Отрицательный результат — тоже файл или строка в разделе «Проверено и пусто» (`handbook/01`, раздел 4).
